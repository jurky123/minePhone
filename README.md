# BrowserLink 0.9.4 — Forge 1.20.1

电视、电脑和手机显示同一条 Chrome 页面，沿用已有登录状态，不复制 Cookie。

## 0.9.4 全屏对照与发送恢复

- 修复发送缓冲区拥塞后只能等待后续策略更新才恢复的问题：使用工作线程短时检测缓冲区，不依赖隐藏页面定时器。停止连接时清理检测线程。
- 增加捕获端性能诊断，游戏仅在 QA benchmark 模式记录数值；普通游戏不持续打印性能日志。
- 保留原版 F11；没有强制切换 F6，也没有改动 Chrome 启动参数或 Windows 显卡配置。
- 使用建议：Chrome 连接页面，720p / 30 FPS / JPEG，开启“后台流畅模式”，保留辅助小窗，再返回游戏使用 F11。网页切换后需重新开启辅助。
- 焦点模拟、CPU 画布、同步编码、未压缩像素传输均已实测，未能稳定改善无辅助窗口的全屏播放，未作为正式功能发布。无辅助窗口全屏卡顿尚未解决。
- 本机独立 QA 存档的五分钟结果见 TESTING.md；不代表完整整合包和所有视频网站都已流畅。原版 F11 不等于已验证底层独占呈现，Windows 全屏优化可能介入。

## 0.9.3 点击位置与兼容全屏

- 修正捕获画面额外黑边造成的点击偏移：捕获宽高跟随当前网页实际比例，缩放窗口后自动更新；指针映射包含滚动条占用的宽度。
- F6 切换“浏览器兼容无边框全屏”，画面铺满显示器，允许 Chrome 浮窗保持置顶。再次 F6 返回窗口；F11 仍为原版全屏。每次启动需自行启用，不强制更改整合包的全屏偏好。
- 也可以在浏览器显示设置中切换兼容全屏。F6 冲突时可在 Minecraft 按键设置改键。
- 推荐顺序：Chrome 连接网页 → 开启后台流畅模式 → 回游戏按 F6。保留小浮窗；切换或导航网页后重新开启。视频建议 720p / 30 FPS / JPEG。
- 全屏不是已证实的唯一卡顿原因。本机短时原版 F11 和兼容 F6 都达到接近 30 FPS；完整整合包、视频网站及显卡负载仍需进一步验证。

## 0.9.3 后台流畅模式与副手支持

- Chrome 扩展新增“开启 / 关闭后台流畅模式”：连接目标网页后点击，保留小浮窗可见，再切回窗口模式的游戏。小窗只显示说明，不搬走原网页视频。
- 关闭小窗即可结束该模式。切换标签或网页导航后需要重新开启；普通 HTTPS 网页需浏览器支持 Document Picture-in-Picture。不会替换用户已有画中画。
- 修正视频 Worker 的帧率调度，避免 30 FPS 来源的轻微到帧抖动导致连续丢帧；编码队列仍有界，不积压旧画面。
- 本机测试表明：Chrome 主窗口完全被游戏遮挡、保留小浮窗时，720p30 视频恢复至约 29–30 FPS。详细采样与限制见 TESTING.md；不是所有网站和完整整合包的性能保证。
- F8 优先打开主手手机，否则打开副手手机；两手都没有手机时打开普通浏览器界面。
- Shift + 右键优先使用副手手机，避免主手方块抢先放置。普通右键仍遵循 Minecraft 的主手优先规则。
- F7 支持副手横竖屏，左手屏幕文字保持正向；近屏交互与声音选择跟随实际使用的手。

## 显示设置与交互

- 按需刷新默认开启：没有显示需求约 2.5–3.5 秒后停止画面捕获；重新显示后通常在下一个 1 秒心跳内恢复。声音独立，不因停止图像传输而关闭。
- 手持/普通小屏上限 720p / 30 FPS，12 格内电视上限 1080p / 30 FPS，右键近屏上限 1440p / 30 FPS。最终画质和帧率始终取扩展手动上限与自动档位的较小值。
- 可见性采用保守的渲染、方向与距离提示，不做昂贵的逐像素遮挡检测；墙后、视野边缘或物品栏中的模型预览可能保持传输。此功能停止捕获链路，不会冻结网页脚本或视频播放。
- 需要恒定画质可在显示设置关闭自适应；游戏暂停/退出世界仍停止画面，断线与音频恢复沿用既有逻辑。
- **F7**：手持手机时切换横竖屏，可在 Minecraft 按键设置重新绑定。竖屏自动缩小并提高位置，默认完整显示。
- 右键设备后点底栏 **设置**，或 **Ctrl+,**：调整手持大小、左右/上下位置、手机近屏大小；滑块设置自动保存在 `config/browserlink-display.json`。这些参数属于本机客户端，不修改物品 NBT。
- **F9**：开关性能面板，在世界或浏览器界面显示接收/上传帧率、MiB/s、最近一次解码/上传耗时、累计丢弃帧及当前档位。默认关闭，可重新绑定世界内按键。这里的 GPU 帧率是浏览器纹理上传次数，不是 Minecraft 游戏帧率；上传耗时是 CPU 调用耗时，不是 GPU 完成耗时。
- **Ctrl+I**：文字输入框。编辑输入框时优先处理本地编辑按键，Ctrl+W 等浏览器操作不再抢走按键；Esc 先返回网页，保留草稿；Enter 发送，Ctrl+Enter 发送并向网页提交。草稿只在当前游戏进程内保留，不写入磁盘。此版没有新增 Windows 原生 IME 集成。

## 既有切页与横屏功能

- 修复切换标签页后没有画面：切换时主动获取首帧，捕获停顿时自动补帧；重新选择当前标签也会重启捕获。
- 声音初始化与切页分开，音频未授权不会卡住页面操作；过期截图不会覆盖新页面。
- 手机在第一、第三人称手持时横放，网页文字保持正向；第一人称模型放大并提高位置，右键仍进入近屏操作。已有手机直接生效。
- 视频捕获未授权或失效时保留兼容截屏，后台可能只有约 1 FPS。到 Chrome 打开目标网页，点击扩展“连接当前标签页”，确认显示“标签页视频流”。切到另一个新标签可能需要再次点击授权；最小化和受保护视频未逐站验证。
- 补帧只缩放输出像素，不改变网页布局或浏览器缩放。保留你现有的清晰度设置；想更清楚可在扩展中选择 1080p/1440p。

## 电视与位置音效

- 使用用户提供的 voxel_tv_complete.zip：152 个机身部件加独立屏幕，约 3 格宽、1.94 格高，16:9 屏幕约 2.62 格宽。
- 放置需要 3×2 格空间，朝向玩家；任意屏幕部分可右键进入近屏交互。生存模式拆任意部分只掉落一台，其他占位自动清除。整台模型只渲染一次。
- 电视与电脑、手机共用当前标签页、滚动位置和页面状态。Esc 返回游戏；电视继续显示画面。
- 扩展捕获所选标签音频，经本机 WebSocket 传入 Minecraft 的位置声音系统。最近右键交互的电视/电脑/手机成为唯一声源，避免多设备回声。
- 转身和走动会改变声源方向，约 24 格内线性距离衰减；受游戏主音量及“唱片机/音符盒”控制。手机声源随持有者移动。
- 退出近屏操作不停止电视声音。设备失效、退出世界、断线或游戏暂停时恢复 Chrome 普通播放，避免捕获后一直静音。心跳超时也会恢复浏览器播放。
- 位置音效使用 48 kHz、16-bit 单声道，双声道原音先混合再由游戏做空间定位。缓冲有限，不积压长段音频。不是原网站立体声直通，暂不模拟墙体遮挡、房间反射或环绕家庭影院。
- 此版音效为实验功能，图片和音频分开传输，可能有少量不同步；高负载、后台 Chrome 节流或音效模组组合需要进一步实测。

## 如何使用

1. 重启整合包。Chrome 扩展文件已在原加载目录更新到 0.9.3；若浏览器仍加载旧代码，请在 chrome://extensions 点击 BrowserLink 的重新加载按钮。
2. 打开要看的网页，点击工具栏 **B / BrowserLink → 连接当前标签页**。扩展新增 tabCapture 权限，只捕获所选标签，不读取麦克风或整个系统音频。
3. 看视频先设 720p / 30 FPS / JPEG，确认状态为“标签页视频流”。需要文字清晰度可提高到 1080p/1440p，或切换 PNG；高分辨率会增加开销。原 Chrome 窗口太小不会产生更多细节。
4. 创造模式“功能方块”中找到“浏览器电视”，留出 3 格宽、2 格高的空间放置。也可用下方命令或合成配方。
5. 右键电视屏幕，播放网页音视频。该电视成为声源；按 Esc 后可绕电视走动体验方向和距离变化。
6. 若声音仍从 Chrome 播放，先右键一次目标设备；若扩展提示音频未授权，回 Chrome 对当前标签再点一次连接。Chrome 的标签音频授权无法保证随任意新标签自动转移，但画面切换不受影响。

```mcfunction
/give @s browserlink:television
/give @s browserlink:computer
/give @s browserlink:phone
/give @s browserlink:computer_chair
```

电视合成：上排 3 块玻璃板；中排 铁锭/浏览器电脑/铁锭；下排 铁锭/红石/铁锭。
电脑椅右键坐下，Shift 起身；手机对空气右键近屏，底部旋转切换横竖屏。

## 输入与标签页

- ×、中键、Ctrl+W 关闭；关闭当前页先切相邻页，最后一页变成空白页。
- Ctrl+T / + 新建空白页，Ctrl+Tab / Ctrl+Shift+Tab 切换，Ctrl+L 输入网址，Ctrl+R / F5 刷新，Alt+左右后退/前进。
- 点击网页输入位置后按 Ctrl+I 打开底部中文输入框；Enter 发送后回到网页，Ctrl+Enter 发送并提交。Ctrl+V 可粘贴中文。原生中文候选窗仍依赖 Minecraft/输入法兼容性。
- Ctrl+A/C/X/V/Z/Y：全选、复制、剪切、粘贴、撤销、重做。密码框不导出剪贴板内容。
- Ctrl+滚轮 / Ctrl+加减号改变真实网页缩放，Ctrl+0 恢复；Shift+滚轮横向滚动。
- Esc 退出近屏；F8 打开持有的手机，否则打开普通网页界面。手机声音跟随本次使用的手。

## 限制与验证

仅监听 127.0.0.1:19285，校验固定扩展 Origin，单客户端一个浏览器连接。不向 Minecraft 服务器传图片或音频，其他玩家不会看到或听到你的浏览器。
Chrome 内部页、原生对话框、受保护视频不保证可捕获。手机竖屏保持原桌面网页比例，会有黑边。
独立 Forge 47.4.16 世界已验证模型、近屏点击、共享页面、自动重连、音频接收与位置声源启动、退出近屏持续发声、拆除清理和声源释放。
未做目标整合包全部其他模组联合测试，也未做扬声器声场/端到端延迟测量；测试日志不能替代实际耳机听感。

开发：`gradlew build`、`gradlew runClient`、`node --test extension/tests/*.cjs`；模型转换器 `tools/convert_tv.py` 仅读取模型数据和贴图，没有运行归档附带脚本。
