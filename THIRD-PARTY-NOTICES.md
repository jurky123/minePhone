Ownership remains with the asset author; the code MIT license does not grant a separate license to this supplied asset. The conversion script and source geometry are included for the user's continued editing.
- The gaming chair model and chair_atlas.png are converted from the user-provided voxel_gaming_chair_complete.zip (169 authored cuboids). Ownership remains with the asset author; the code MIT license does not license the supplied asset. Exact rotated geometry is exported as Forge OBJ. Source geometry and the conversion script are included.

- The phone model, phone_body_atlas.png and phone_screen.png are converted from the user-provided voxel_phone_complete.zip (84 body cuboids plus an independent display quad). Ownership remains with the asset author. The code MIT license does not license the supplied asset. Source geometry and a data-only converter are included; archive scripts were not executed.
